# REPLY REACTOR 3000 — ALIEN MATH applied to self-replies

**Experimental, opt-in, offline-first and deliberately ridiculous.**

**VANILLAJS v1.7.0 — Reply to Your Own Tweets Edition** supplies the source-owned
finite-field engine and deterministic reference sound. TWEET-TO-YOURSELF keeps
posts local and never communicates with X/Twitter, a surveillance system or an LLM.

## Mathematical contract

The reactor is a **classical** game state over GF(3), the three-element field
{0,1,2}. It is not a quantum system, amplitude simulator, actual qutrit or
intelligence-monitoring device.

The initial ego state is \`s = [x,y] = [0,0]\`. A source-owned new post
(\`parentId === null\`) applies

    POST  : [x,y] -> [x+1, y] mod 3

A self-reply (\`parentId !== null\`) applies

    REPLY : [x,y] -> [x+y, y+1] mod 3

The POST matrix is identity; the REPLY matrix is the invertible shear
[[1,1],[0,1]]. Both are validated by the authentic VANILLAJS
\`affineTransform\` API and committed via \`transition\`. All field arithmetic
is on exactly representable small integers; there is no Float64 rounding
ambiguity in these state transitions.

The optional, deliberately worthless challenge is to reach target state
\`[2,1]\`. Every transition **whose after-state** equals that target earns
one *self-win*. The achievement does not change posts or authoritative state.

### Deterministic score window

Only the **last 32 posts**, in original ascending ID order, are reprojected.
The window starts from [0,0] even if earlier posts exist, and its tick
indices are 1..N. Earlier posts remain persisted but are reported as
\`omittedPosts\` and do not change the current music window. This is not
a hidden deletion or a complete-history proof.

A declared mapping sums after-state coordinates modulo 3 and chooses:
- Note 0: 196 Hz.
- Note 1: 294 Hz.
- Note 2: 392 Hz.

Waveform is triangle; gain is 2800, each event occupies one 4-Hz tick,
and no unseeded randomness, wall clock, volume slider, graphics pixel or
audio-device output feeds the mathematical model.

The immutable source object is generated by \`buildReplyReactor(archive)\`.
\`reactorLog(result)\` emits detached JSON containing **only post IDs,
transition operations, states, notes and metadata**; it includes no user
post text, storage data, account identifier or browser device information.
\`reactorReferenceWav(result)\` produces the authentic VANILLAJS
integer-PCM 48 kHz/16-bit/mono reference (up to 8 seconds). A zero-post
archive has no WAV and correctly rejects a requested PCM export.

The browser can optionally convert that PCM into floating-point AudioBuffer
samples for listening. This resampling/playback layer is deliberately not
identity-bearing. Tab hiding and new posts stop stale audio, while data
generation still works with AudioContext unavailable.

### Multi-tab and privacy boundary

The existing \`ArchiveStore\` remains authoritative for all post changes,
conflict checks and storage events. The reactor is a **pure read-only
projection** of the validated stored archive: no extra persistent keys, no
saved game state, no external network access and no cross-tab write policy
changes. Resetting or reloading recomputes the exact same result for the same
local post sequence.

The app retains its existing sequential stale-tab rejection policy; localStorage
does not offer a true atomic compare-and-swap for simultaneous writers.

## Reproduction

    node --test tests/*.test.mjs
    python3 scripts/verify_site.py

Node tests cover hand-calculated GF(3) sequences, reversibility through the
reviewed upstream module, a goal-state achievement, bounded 32-post windows,
audio identity, source blob SHA-1, malformed inputs and absence of user text in
the exported event log.

The GitHub Pages workflow deploys a **source-allowlisted ten-file runtime**
only on a successfully verified \`main\` push. Pull requests run CI but do
not deploy. Real browser hardware/audio playback and hardware-wide performance
are outside the mathematical test proof.
